# mlops-journey
mlops-journey
Месяцы 1–3: Закрыть DevOps-дыры + английский
 
Цель: k8s 2, Terraform 1.5, AWS 2, Monitoring 1.5.
• [ ] Kubernetes (2 ч/нед): не «смотрел курс», а разверни minikube/kind локально, задеплой приложение, StatefulSet, ConfigMap, Secrets, Ingress, HPA. Это приоритет №1.
• Terraform (1 ч/нед): HashiCorp Learn, разверни EC2 + S3 + IAM. Потом EKS.
• AWS (1 ч/нед): S3, EC2, IAM, VPC, ECS/EKS, CloudWatch. Готовься к AWS Solutions Architect Associate — это добавит веса резюме.
• Monitoring (0.5 ч/нед): Prometheus + Grafana. Разверни в k8s, собери метрики.
• Английский (0.5 ч/нед): speaking + технический словарь. Это не опция. 
Артефакт: репо devops-lab с k8s-манифестами, Terraform-модулями, Prometheus-конфигом.
 
Месяцы 4–6: ML-минимум
 
Цель: понимать, что деплоишь.
• Python для ML (1.5 ч/нед): NumPy, Pandas, scikit-learn. Не с нуля — ты Python 2.
• Классический ML (1.5 ч/нед): регрессия, деревья, бустинги (CatBoost), метрики, кросс-валидация. Не глубоко.
• PyTorch базово (1 ч/нед): обучить, сохранить, загрузить. Без исследований.
• SQL (0.5 ч/нед): добить оконные функции (у тебя пробел, я видел).
• Английский (0.5 ч/нед): speaking. 
Артефакт: обучение CatBoost на табличных данных + сохранение в pickle + логирование в MLflow.
 
Месяцы 7–9: MLOps-ядро
 
Цель: end-to-end пайплайн.
• MLflow (1 ч/нед): tracking, model registry, проекты.
• DVC (0.5 ч/нед): версионирование данных и моделей.
• Serving (1 ч/нед): FastAPI + ONNX/Triton/BentoML. Деплой модели в k8s.
• Airflow/Prefect (1 ч/нед): ML-пайплайны (retraining, data validation).
• Drift monitoring (0.5 ч/нед): Evidently + Prometheus. Ключевое отличие MLOps от DevOps.
• Английский (1 ч/нед): speaking, подготовка к интервью. 
Артефакт: mlops-project — данные → обучение → MLflow → Docker → k8s → мониторинг. Это твой главный проект для портфолио.
 
Месяцы 10–12: Специализация + работа
• ML System Design: книга Chip Huyen «Designing ML Systems».
• LeetCode: 100 задач (Python + SQL).
• Резюме: переписать под MLOps, на английском.
• LinkedIn: активный профиль, рекрутеры.
• Отклики: 30–50 в неделю, сначала remote, потом релокация.
• Английский: довести до B2. 
Артефакт: 3 проекта на GitHub + резюме + профиль LinkedIn.
